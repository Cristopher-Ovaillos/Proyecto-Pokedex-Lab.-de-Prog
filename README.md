# Proyecto-Pokedex-Lab.-de-Programación

Requisitos:
- Node JS + express.
    - https://nodejs.org/es/download
    - https://expressjs.com/ 

## Ejecucion

```
cd backend
npm i
cd ..
cd frontend
npm i
cd ..
#fin
```

## Backend:

1. cd backend

    - Si es la primera vez usar: npm install
    - Este instalara las dependencias definidas en package.json 

2. npm start.

*Ejecutar este comando, permitira visualizar en la terminal los endpoints consumibles con su respectiva clasificacion.*

3. Usar EXPO GO, deberemos dirigirnos a: backend/src/shared/config.js y reemplazar localhost por nuestra IP. Debido a que que localhost hace referencia a nuestro dispositivo y no a otro dispositivo en nuestra red.
    - Windows: ipconfig.
    - linux mint: ip address show
  
## Frontend:
1.  Dependencias
```bash
    cd frontend
    npm install
```
2. Reemplazar IP
   
   Dirigirse a frontend/src/config/index.js y reemplazar por nuestra IP

4. Iniciar la app y usar EXPO GO
```bash
    npm start
```
