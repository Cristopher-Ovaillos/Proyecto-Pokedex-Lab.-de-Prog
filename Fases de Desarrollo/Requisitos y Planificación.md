# Requisitos y Planificación

**Descripción del Dominio:**

En laboratorio de programacion 2023, se desarrollo un sitio web relacionada con la serie animada Pokemon, mas especifico con la "Pokedex". En esta nueva etapa, se creara una aplicacion movil que incluira una API que sera consumida para satisfacer las necesidades. 

El sistema completo debera permitir a los usuarios:
- Registrarse,Iniciar/cerrar sesion con sus cuentas.
- Acceder a su perfil, con el objetivo de ver y modificar sus datos (ej. nombre de usuario, contraseña).
- Visualizar toda la pokedex (disponible generacion[1-5]).
    - Visualizar imagen del pokemon, id, tipos, estadisticas, y movimientos.
    - Filtrar por generacion, por tipo, por estadistica.
- Crear un equipo pokemon (max 6 por equipo), guardar, editar.

    - Esto incluye editar pokemon sea sus evs, ivs, naturalezas, set de movimiento (no incluimos items).
    - eliminar equipo pokemon.

- Visualizar todos los movimientos disponible y quien lo aprende.

**Requisitos funcionales y no funcionales:**

Requisitos funcionales:
- Los usuarios deberan poder iniciar sesion con su nombre de usuario y contraseña.
- Los usuarios deberian poder ver sus equipos pokemon sean completos o no.
- Los usuarios deberan poder cambiar sus nombres de usuarios y contraseñas.
